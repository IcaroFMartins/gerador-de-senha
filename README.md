# Gerador de Senhas

Programa de linha de comando em Python que gera senhas aleatórias seguras.

## Como executar

```bash
python3 main.py
```

## Funcionalidades

- Definir o tamanho da senha
- Incluir ou não letras maiúsculas
- Incluir ou não números
- Incluir ou não símbolos
- Avaliar a força estimada da senha

## O que aprendi

- Usar o módulo `secrets` para aleatoriedade segura
- Criar funções com parâmetros opcionais
- Validar entradas do usuário
- Separar lógica de interface
- Usar `string.punctuation`, `string.digits` e `string.ascii_letters`
